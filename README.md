# Mycelium slides

Decks from talks and workshops about [Mycelium](https://github.com/mycelium-io/mycelium), published at <https://mycelium-io.github.io/slides/>.

Each talk lives in its own folder and gets its own link: `mycelium-io.github.io/slides/<talk>/`. A deck is plain HTML, copied here from `mycelium-deck/` in the main repository when the talk is ready to share.
